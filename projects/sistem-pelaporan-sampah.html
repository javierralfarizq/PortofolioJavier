UI/UX Design

Sistem Pelaporan Sampah

Perancangan UI/UX aplikasi pelaporan sampah untuk mendukung proses pencatatan dan pengelolaan data sampah. Desain mencakup antarmuka aplikasi mobile bagi petugas dan dashboard admin untuk mendukung proses pengelolaan serta rekapitulasi data sampah.

Lihat Desain Figma Diskusikan Proyek
Role UI/UX Designer
Tools Figma
Platform Mobile App & Dashboard Admin
Output Wireframe, UI Design, Prototype

Ringkasan Proyek

Desain untuk mendukung proses pelaporan sampah

Latar Belakang

Proyek ini berfokus pada perancangan antarmuka aplikasi pelaporan sampah. Aplikasi dirancang untuk membantu petugas dalam mencatat data sampah, sementara dashboard admin digunakan untuk mendukung proses pengelolaan dan rekapitulasi data.

Tujuan Desain

  • Membuat proses pencatatan data sampah lebih mudah
  • Membantu petugas menggunakan aplikasi secara efisien
  • Menyajikan dashboard admin yang jelas dan fungsional
  • Mendukung proses rekapitulasi data sampah

Fitur Utama

Fitur yang dirancang

Pencatatan Data Sampah

Antarmuka untuk membantu petugas mencatat data sampah dengan lebih sederhana dan terstruktur.

Pelaporan

Alur pelaporan yang dibuat agar mudah dipahami oleh petugas di lapangan.

Dashboard Admin

Dashboard untuk mendukung proses pengelolaan dan rekapitulasi data sampah.

Proses Desain

Tahapan perancangan

1. Memahami Kebutuhan

Menentukan kebutuhan utama pengguna, yaitu petugas yang melakukan pencatatan data sampah dan admin yang mengelola data.

2. Wireframing

Menyusun struktur halaman dan alur penggunaan aplikasi sebelum masuk ke tahap desain visual.

3. UI Design

Merancang tampilan antarmuka mobile dan dashboard admin menggunakan Figma dengan fokus pada kejelasan dan kemudahan penggunaan.

4. Prototype

Membuat prototype sederhana untuk menggambarkan alur penggunaan aplikasi.

Kesimpulan

Hasil akhir proyek

Proyek ini menghasilkan desain antarmuka aplikasi mobile untuk petugas dan dashboard admin untuk mendukung pengelolaan data sampah. Desain dibuat dengan pendekatan yang sederhana, fungsional, dan mudah digunakan.
