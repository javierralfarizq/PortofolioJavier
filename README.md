# Portfolio Javieryan Alfarizq

Website portofolio static multipage untuk Javieryan Alfarizq.

Dibuat menggunakan:

- HTML
- CSS
- JavaScript

Tanpa database dan tanpa framework.

- Beranda
- Tentang
- Proyek
- Detail Proyek Sistem Pelaporan Sampah
- Detail Proyek DriverLog
- Pengalaman
- Kontak
